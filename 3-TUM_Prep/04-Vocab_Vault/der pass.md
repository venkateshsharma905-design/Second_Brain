# der Pass

- **Meaning:** The passport
- **Grammar Notes:** Masculine noun. In the accusative case (direct object), "der" changes to "den" (e.g., *Ich habe den Pass*).

## Example Sentence
> Hier ist der Pass. (Here is the passport.)
